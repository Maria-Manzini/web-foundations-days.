About QuickNotes

QuickNotes is a small web app for capturing short ideas the moment they arrive, before they slip away. It keeps one job in front of you at a time: write a note down, then see it in your list.

How to use QuickNotes

  1. Open the Home page and find the "Add a note" form.
  2. Type your note into the text field.
  3. Press the "Add Note" button to save it.
  4. Scroll to "Your notes" to read everything you have captured.

Features

  • Fast, distraction-free note entry
  • A running count of your saved notes
  • Clean, readable list of every note
  • Works on desktop and mobile screens

Keyboard shortcuts

Shortcut Action
Enter Submit the current note
Tab Move to the next field
Esc Clear the note input
